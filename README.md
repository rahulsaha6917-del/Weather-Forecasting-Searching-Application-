# 🌦 Weather Forecasting & Search App

A modern and responsive **Weather Forecasting Application** that allows users to search weather data for any city — with current weather, 5-day forecast, weather icons, auto-location detection, unit toggle, and dark/light mode support.

Built using **HTML, CSS, and JavaScript**, this app demonstrates real-world API integration and polished UI design.

---

## 📌 Features

✅ Search weather by city name  
✅ Auto-detect user location  
✅ Current temperature & conditions  
✅ 5-day weather forecast  
✅ Weather icons from OpenWeatherMap  
✅ Celsius ↔ Fahrenheit toggle  
✅ Dark / Light theme toggle  
✅ Mobile-first responsive design  
✅ Clean and modern UI

## 🧠 How It Works

The app fetches live weather data from the **OpenWeatherMap API**.  
It displays:
- Current weather
- Weather icons
- Forecast for the next 5 days
- Toggle between Celsius & Fahrenheit
- Auto-detect location using browser Geolocation API
